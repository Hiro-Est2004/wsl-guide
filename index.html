Windows Subsystem for Linux (WSL) 上で
Python 開発環境を構築する

（2026年版）
WSL のインストール方法が大幅に簡略化されました。 以前は dism.exe コマンドを複数回実行し、手動でカーネルをダウンロードし、Microsoft Store から Ubuntu を入れる必要がありましたが、 現在は コマンド1行 で完結します。
VS Code との連携も大幅に簡単になっています。
目次

    ここではWindows 上でLinux 系OS（Ubuntu）を動かすためのWSL 導入方法と、WSL 上でPython 開発環境を構築する方法を示す。基本的にページの上から順に進めることを前提としており、順序を守らないとうまくいかない可能性がある。

    1. WSL + Ubuntu のインストール

    以前は複数のコマンドと手動ダウンロードが必要でしたが、現在は 1 コマンド で WSL2 + Ubuntu が一括インストールできる。

    インストール手順

    1
    PowerShell を管理者として起動する
    スタートメニューを右クリック →「Windows PowerShell（管理者）」または「ターミナル（管理者）」を選択。
    2
    以下のコマンドを実行する 
    wsl --install -d Ubuntu
    このコマンド1つで以下がすべて自動で行われる：
    • WSL 機能の有効化
    • 仮想マシン機能の有効化
    • WSL2 カーネルのインストール
    • Ubuntu 最新LTS のインストール
    注意： wsl --install（オプションなし）だけではUbuntu が自動でインストールされないケースがある。 必ず -d Ubuntu を付けること。
    バージョン指定について： -d Ubuntu はその時点での最新LTS が入る（現在は 24.04）。 特定バージョンに固定したい場合は -d Ubuntu-24.04 のように指定する。
    インストール可能な一覧は wsl --list --online で確認できる。
    3
    PC を再起動する（必ず）
    4
    Ubuntu を起動する
    再起動後、Ubuntu は自動起動しない。以下のいずれかの方法で手動起動する：
    • PowerShell / コマンドプロンプトで wsl と入力して実行
    • スタートメニューで「Ubuntu」と検索してクリック
    5
    ユーザー名・パスワードを設定する
    初回起動時に Linux のユーザー名とパスワードの設定を求められる。任意のものを設定する。 
    Enter new UNIX username: （任意のユーザー名を入力）
New password: （任意のパスワードを入力 ※入力中は表示されない）
Retype new password: （同じパスワードを再入力）
passwd: password updated successfully
Installation successful!

    2. Python 環境構築

    2.1 環境パスの設定

    初期設定ではWSL の環境パスがWindows の環境パスを内包している。 Windows 側でPython がインストール済みだと競合するため、WSL の環境パスを独立にする。

    以下のコマンドで設定ファイルを開く：

    $ sudo nano /etc/wsl.conf

    開いたファイルに以下を追加する：

    [interop]
appendWindowsPath = false

    保存後、PowerShell で以下を実行してディストリビューションを再起動する：

    wsl --shutdown

    2.2 apt のアップデート

    $ sudo apt update
$ sudo apt upgrade -y

    ビルドに必要な基本パッケージをインストールする：

    $ sudo apt install -y build-essential

    2.3 pyenv のインストール

    複数のPython バージョンを管理できるpyenv をインストールする。

    まず依存パッケージをインストールする：

    $ sudo apt install -y git libedit-dev libncurses5-dev libbz2-dev \
    libreadline-dev libsqlite3-dev zlib1g-dev libssl-dev \
    libffi-dev liblzma-dev

    pyenv をクローンする：

    $ git clone https://github.com/pyenv/pyenv.git ~/.pyenv

    以下のテキストを ~/.bashrc の末尾に追加する。nano を使うと簡単に編集できる：

    1
    ファイルを開く 
    $ nano ~/.bashrc
    2
    キーボードの ↓ キーで一番下まで移動し、以下を入力する 
    export PYENV_ROOT="$HOME/.pyenv"
export PATH="$PYENV_ROOT/bin:$PATH"
eval "$(pyenv init -)"
    3
    保存して閉じる
    Ctrl + X → Y → Enter
    4
    反映させる 
    $ source ~/.bashrc

    動作確認：

    $ pyenv --version
pyenv 2.x.x

    2.4 Python のインストール

    末尾5件に絞ってインストール可能なバージョンを確認する：

    $ pyenv install --list | grep -E "^\s+3\.[0-9]+\.[0-9]+$" | tail -5

    3.12 系の最新版をインストールする：

    $ pyenv install --list | grep -E "^\s+3\.12\.[0-9]+$" | tail -3
    $ pyenv install 3.12.13
    インストール時に以下の警告が出ることがあるが無視してOK： 
    WARNING: The Python tkinter extension was not compiled and GUI subsystem has been detected. Missing the Tk toolkit?
    tkinter とは、ボタン・入力欄・ウィンドウなどの視覚的要素を持つデスクトップアプリを作るための GUI ライブラリ。 データ分析や Jupyter では使わないため、この警告は無視して問題ない。
    バージョンの選び方（2026年5月時点）：
    3.14 系は最新だがリリースされたばかりで不安定な可能性がある。 現時点では 3.12 系が安定しており推奨。 3.8 は 2024年10月にサポートが終了しているため、新規環境での使用は避けたほうがいい。

    インストールしたバージョンをデフォルトに設定する：

    $ pyenv global 3.12.13
$ python --version
Python 3.12.13

    pip をアップデートしておく：

    $ pip install --upgrade pip

    3. Jupyter のインストール

    Jupyter Labをインストールする。

    JupyterLab とJupyter Notebookの違い：
    現在は機能が豊富な JupyterLab の使用を推奨する。 Notebook の上位互換で、ファイルブラウザやタブ表示などが使える。 
    $ pip install jupyterlab

    起動方法

    $ jupyter lab

    起動後、ターミナルに以下のような URL が表示されるので、コピーしてブラウザに貼り付けて開く：

    http://localhost:8888/lab?token=xxxxxxxxxxxxxxxx

    終了するときはターミナルで Ctrl + C を2回押す。

    4. VS Code との連携

    旧版ではエイリアス設定や手動パス設定が必要だったが、現在は WSL 拡張機能を使うだけ で完結する。

    セットアップ手順

    1
    VS Code をWindows 側にインストールする
    https://code.visualstudio.com/ からダウンロードしてインストールする。
    インストール時に 「PATH への追加」にチェックが入っていることを確認する。
    2
    WSL 拡張機能をインストールする
    VS Code の拡張機能タブを開き、WSL と検索してインストールする。
    拡張機能ID：ms-vscode-remote.remote-wsl
    3
    VS Code のPATH をWSL に追加する
    以下のコマンドを実行する（ユーザー名 の部分は自分の Windows ユーザー名に変更する）： 
    $ echo 'export PATH="$PATH:/mnt/c/Users/ユーザー名/AppData/Local/Programs/Microsoft VS Code/bin"' >> ~/.bashrc
$ source ~/.bashrc
    4
    WSL ターミナルから code . で起動する
    作業したいディレクトリに移動し、以下を実行するだけ： 
    $ cd ~/myproject
$ code .
    初回のみ VS Code Server が自動でインストールされ、以降は即座に起動する。

    VS Code に以下の拡張機能を追加する

    VS Code の拡張機能タブで以下を検索してインストールする。

    拡張機能ID用途
    WSLms-vscode-remote.remote-wslWSL 連携（必須）
    Pythonms-python.pythonコード補完・デバッグ
    Jupyterms-toolsai.jupyterVS Code 内で .ipynb を直接編集・実行

    5. Tips & ショートカット

    WSL からDropboxへのアクセス

    $ cd /mnt/c/Users/[Windowsユーザー名]/Dropbox

    WSL の管理コマンド

    # インストール済みディストリビューションの確認
wsl --list --verbose

# WSL のシャットダウン
wsl --shutdown

# バックアップ（エクスポート）
wsl --export Ubuntu ubuntu-backup.tar

# 復元（インポート）
wsl --import Ubuntu C:\WSL\Ubuntu ubuntu-backup.tar
